# Joanna Ruby Toledo Portfolio

A responsive multi-tab resume website built with HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a modern browser. For the best local experience, serve the folder with a simple static server.

## Features

- Six-tab resume card
- Keyboard arrow navigation
- Touch swipe support
- Responsive desktop, tablet and mobile layouts
- Reduced-motion support
- Downloadable ATS-friendly CV
- Semantic HTML and structured person metadata

## Deployment

Upload the complete folder to GitHub Pages, Netlify, Azure Static Web Apps, or any static web host.
